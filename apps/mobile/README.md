# Quizzly mobile app

Expo (React Native, TypeScript) app. Not scaffolded yet. It will be created with:

```bash
npx create-expo-app@latest . --template tabs
```

Planned stack: Expo Router, TanStack Query (persisted to expo-sqlite), Zustand, Supabase JS (auth only), Sentry.
See [docs/ARCHITECTURE.md §5.7](../../docs/ARCHITECTURE.md#57-mobile-app).
